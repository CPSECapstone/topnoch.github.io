# NOCH Alpha Release Notes

**Version:** 1.0.0-alpha  
**Release Date:** April 15, 2026

---

## Release Objective

Validate core end-to-end user journeys with real testers while documenting deployment operations, legal terms, and support channels for the NOCH social dining platform.

## What's Included

### Core Features
- 🍽️ Restaurant discovery and detail browsing
- 📅 Reservation and booking user flows
- 📸 Post/reel social interactions and profile controls
- 💬 Messaging and social engagement
- 👤 Account management and preferences

### Infrastructure
- CI pipeline with analysis, tests, and Android build
- GitHub Actions deployment workflow
- Public documentation website (this site!)

### Documentation
- End-user installation guide
- System administrator deployment guide
- EULA and GDPR-compliant privacy policy
- Feedback and defect reporting process

---

## Known Limitations

- Some features depend on backend environment availability
- Cross-platform behavior may differ during alpha testing
- Performance tuning and UX refinements are still in progress

## Report Errors

Report crashes, data issues, authentication regressions, and major first-time-user friction through our feedback channels:

- **GitHub Issues:** [https://github.com/CPSECapstone/noch/issues](https://github.com/CPSECapstone/noch/issues)
