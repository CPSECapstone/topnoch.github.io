## How to Report a Bug

When filing a bug report, please include:

1. **App version**: Use the build version appended to the APK download. 
2. **Platform** (Android / Emulated Android / iOS)
2. **Device model and OS version** (e.g., Medium Phone, Pixel 7, Android 14)
3. **Exact steps to reproduce**: Steps that cause the error.
4. **Expected behavior**: What should have happened or what would be a better reponse?
5. **Actual behavior**: What actually happened?
6. **Screenshots, recordings, or logs** (if available)

## Feature Requests
